**Бутони (`Изображение (2/3).png`):**

## 4. Пълно дърво на екраните (структура за навигация)

> Източник: логическото дърво. Това е скелетът на цялото съдържание.

```
0. Начален избор (HOME)
   ├── Обаждане на клиента  → направление 1
   └── Среща с клиента       → направление 2

1. ОБАЖДАНЕ НА КЛИЕНТА   (навигация: Подготовка → Стъпки → Сценарии → Типове клиенти)
   1.1 Подготовка
       1.1.1 Видове контакти (Студен / Топъл / Регулярен)
       1.1.2 Съвети при подготовка (5 съвета)
   1.2 Стъпки в обаждането
       1.2.1 Отваряне
       1.2.2 Представяне на целта (+ Ключови послания)
       1.2.3 Справяне с възражения (4 примерни + 4 техники: Огледална/Алтернативна/Относителна/Тирбушон)
       1.2.4 Затваряне  (БЕЛЕЖКА: няма подробен текст в мокъпа → placeholder)
   1.3 Сценарии  (всеки = интерактивен FLOW със състояния/избори/краища, НЕ плосък списък)
       1.3.1 Към лоялен клиент          (персонаж: Георги Петров, 38)
       1.3.2 Към предварително одобрен  (персонаж: Даниела Иванова, 34)  — най-разгърнат flow
       1.3.3 По промо кампания          (персонаж: Николай Тодоров, 29)  — ограничени разклонения
       1.3.4 За продукт „Пенсионер"     (персонаж: Мария Стоянова, 67)
       1.3.5 По препоръка               (персонаж: Мария Петрова, 41)
   1.4 Типове клиенти (10 типа — общи и за двете направления)
       Агресивен, Аналитичен, Трудно схватлив, Злонамерен, VIP/ВИП,
       Подозрителен, Манипулативен, Нерешителен, Търсещ социален контакт, Импулсивен

2. СРЕЩА С КЛИЕНТА   (навигация: Подготовка → Стъпки → Сценарии → Типове клиенти)
   2.1 Подготовка
       2.1.1 Видове подход (Активен / Реактивен)
       2.1.2 Съвети при подготовка (Checklist + 3 стратегии: Дългосрочна/Краткосрочна/Имиджова)
   2.2 Стъпки при среща
       2.2.1 Отваряне на разговор
       2.2.2 Идентифициране на нужди (Теми / Въпроси / Нужди)
       2.2.3 Предложение (структура)
       2.2.4 Справяне с възражения (същите 4 техники)
       2.2.5 Затваряне
   2.3 Сценарии (FLOW-ове)
       2.3.1 Нов клиент в офис          (Елица Христова, 31)
       2.3.2 Настоящ клиент за нов кредит
       2.3.3 Настоящ клиент за рефинансиране (Галина Иванова, 39)
       2.3.4 Посещение на адрес          (Иван Колев, 52)
   2.4 Типове клиенти (същите 10 типа)
```

**Сценарийните екрани имат:**
- Информационен екран / персонаж (тип контакт, профил, контекст, цел, подходящи техники, следваща стъпка, „какво да не правиш").
- Екран „Тренирай" → влиза в **симулация с чатбот** (+ често опция „Видео").
- Flow на разговора: реплики → избори на клиента (разклонения A/B/C…) → следващи състояния → различими КРАИЩА:
  - разговорът приключва · приключва със среща · уговорка за повторно обаждане · „очаквайте обаждане от нас" · преминаване към документи.

**Специални бележки за разработка (от автора):**
- Навигацията трябва да позволява връщане към главния избор (Обаждане / Среща).
- Двете направления имат еднаква висока логика → еднакъв шаблон.
- Сценариите = state machine с shared компоненти за общите отваряния.
- Празните/визуални слайдове = навигационни placeholder екрани.
- В мокъпа има грешка: „Злонамерен" е показан с характеристики на VIP (за потвърждение).
